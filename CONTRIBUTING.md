# Contributing

Thanks for your interest in improving soroban-event-indexer!

## Getting started

1. Fork the repo and clone it locally (or use github.dev for doc-only changes).
2. Install Rust via [rustup](https://rustup.rs) if working locally.
3. Run `cargo build` and `cargo test` before opening a PR.

## Pull requests

- Keep PRs focused on a single change.
- Add or update an example in `examples/` if you're changing public behavior.
- Run `cargo fmt` (see `rustfmt.toml`) before committing.

## Reporting issues

Please include your `Cargo.toml` version, network (mainnet/testnet), and
a minimal repro if you're filing a bug.
